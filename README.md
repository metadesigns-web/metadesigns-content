# metadesigns-content

Openbare media voor de Instagram-concepten van MetaDesigns. De AI-marketingagent zet hier elke dag de beelden neer en geeft Metricool vaste links (vastgepind op een commit) naar deze bestanden. Metricool kopieert de media daarna naar zijn eigen server.

- `media/JJJJ/MM/DD/` — afbeeldingen, carrousel-slides, Reels en covers per publicatiedatum
- `tools/render.js` — beeldgenerator in de MetaDesigns-huisstijl
- `AGENT.md` — het draaiboek van de agent

Er wordt nooit iets gepubliceerd zonder goedkeuring: alle posts staan als concept in Metricool.
